# FTC Robotics: First Steps (OnBot Java) 🤖

Welcome! This repository has 3 basic steps to get your new robot moving. 

## 📖 Key Terms & Definitions

*   **REV Control Hub (The Brain):** The computer on the robot where your code actually lives and runs. It connects directly to the motors.
*   **REV Driver Hub (The Controller):** The Android screen you hold in your hands. It connects to the Control Hub over Wi-Fi and lets you select which code to run and plug in your gamepads.
*   **DC Motors:** The "muscles" of the robot that spin infinitely. Used for wheels, intakes, and flywheels.
*   **Servos:** Precision motors that move to exact angles (like an arm or a steering wheel) and hold their position.
*   **OnBot Java:** A coding environment that lives right in your web browser! No software to install—just connect to the robot's Wi-Fi and write code.
*   **FTC SDK:** The "Software Development Kit." It's the huge library of pre-written code provided by FIRST that lets you type `hardwareMap.get()` to easily talk to physical robot parts.

## 🚀 The Curriculum

We have three files here to help you learn:

1.  **`Step1_ButtonDrive.java`** - The absolute basics. Push a button, motor turns on. Push another button, motor turns off. 
2.  **`Step2_JoystickDrive.java`** - Connecting the analog joysticks to motor speeds. Half-push = half-speed!
3.  **`Step3_CarSteering.java`** - The final challenge. How do we mix forward/backward with left/right turning? (You'll have to write some code here!)

## 💻 Moving to Android Studio (Bonus Step!)

Once you've mastered these in OnBot Java, it's time to graduate to the big leagues. 
1. Download Android Studio to your laptop.
2. Clone your team's FTC robot controller GitHub repository.
3. Copy these `.java` files into `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/`.
4. Connect your laptop to the Control Hub using a USB-C cable (or Wi-Fi ADB).
5. Click the big green **"Play"** button in Android Studio to build and push the code directly to the robot!
